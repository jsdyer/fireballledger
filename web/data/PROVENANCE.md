# Fireball Ledger data provenance

## Event captures

Publisher: NASA/JPL Center for Near Earth Object Studies (CNEOS).
Endpoint: https://ssd-api.jpl.nasa.gov/fireball.api
Documentation: https://ssd-api.jpl.nasa.gov/doc/fireball.html
Usage policy: https://ssd-api.jpl.nasa.gov/doc/
Context: https://cneos.jpl.nasa.gov/fireballs/

Each capture preserves source signature, field names, query parameters, retrieval time, original record values and change evidence. Values are source reports, not independent measurements by CoolCode. No exclusive ownership over the source values is claimed. The page uses no NASA/JPL branding or endorsement.
