THE CATALOGUE CAN CHANGE
What did the source revise?
CNEOS supplies no immutable event ID. Matches use the reported event time. A corrected time can appear as an added and an absent record; those labels do not prove a newly occurring or deleted event. Comparisons are made only between captures with identical collection settings.


Keep the light in context.
A report, not a census
These are observations released to CNEOS from U.S. Government sensors. Not every fireball is reported, updates are not real time, and CNEOS does not independently verify or reanalyse each event. A blank field means the value was not supplied.
CNEOS data and operational context
Dates & revisions
Event times describe peak brightness in UTC. The capture date says when this tool retrieved the catalogue. Weekly captures retain published values and comparisons, with the newest 52 captures kept by default. The first capture is a baseline; it cannot reveal older edits.
Field definitions and units
Your browser, your filters
Filtering and exports run locally. This page reads saved data from CoolCode and does not query the JPL API. A scheduled GitHub job makes one cached, identified request. No account or API key is required. The basemap is public-domain Natural Earth data.
